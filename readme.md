Please note that you'll need to add the necessary dependencies to your Cargo.toml file:



[dependencies]
hidapi = "0.9.0"
bluetooth = "0.4.1"
#
Replace '00:00:00:00:00:00' with the actual Bluetooth address of your Lovense device when controlling via the app.
